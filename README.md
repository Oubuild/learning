# 📚 学习专区 · Learning Hub

oubuild 的**学习笔记 / 习题 / 练习代码**统一入口。可部署的项目见 [组织首页](https://github.com/oubuild)。

> 边界：这里只收「学」——笔记、习题、练习代码、面试题库；成品项目仍放在 oubuild 主仓库列表，嵌入式专项留在 `Lab0x-Embedded`。

## 目录

### C / C++

| 仓库 | 内容 | 标签 |
| --- | --- | --- |
| [oubuild/cstudy](https://github.com/oubuild/cstudy) | C 语言学习笔记与练习代码集（`exercises` 练习、头文件、编译脚本），含 `main` / `windows` 两个分支 | `c` `exercises` `notes` |
| [oubuild/cpp-docs](https://github.com/oubuild/cpp-docs) | C++ 基础知识 + C/C++ 库函数手册，在线站 [cpp.ryanuo.cc](https://cpp.ryanuo.cc/) | `cpp` `cplusplus` `reference` `docs` |
| [oubuild/cpp-quiz](https://github.com/oubuild/cpp-quiz) | C++ 面试刷题助手，AI 实时生成题目，在线站 [cpp.ryanuo.cc/cppinterview](https://cpp.ryanuo.cc/cppinterview) | `cpp` `interview` |

## 分类约定

- 所有学习类仓库统一打 **`learning`** topic，再按语言 / 方向附加 `c`、`cpp`、`embedded`、`interview`、`notes`、`reference` 等。
- 按 topic 筛选：[github.com/search?q=org%3Aoubuild+topic%3Alearning](https://github.com/search?q=org%3Aoubuild+topic%3Alearning&type=repositories)
- 新增学习仓库时：放进 oubuild → 打 `learning` → 回来补一行到本表。
